## LinkedIn Project Description

**Title**: Enterprise Decision Intelligence & Business Insight Generation Platform
**Description**:
Developed a production-grade Decision Intelligence Platform built using a clean architecture that turns raw Brazilian e-commerce transaction data (Olist) into predictive forecasts, explainable risk models, and prescriptive business recommendations.

**Key Accomplishments**:
- Engineered a robust data ingestion, cleaning, and validation pipeline validating business logic schema profiles.
- Programmed and optimized machine learning models (XGBoost & Random Forest) for Revenue forecasting, Customer Churn prediction, and Inventory Demand forecasting.
- Embedded SHAP (Explainable AI) to demystify black-box model inferences, rendering local and global feature attribution graphs directly onto the client dashboard.
- Architected a prescriptive business recommendation engine mapping predictive risk levels to concrete recommendations with estimated ROI, horizons, and confidence scores.
- Containerized the full-stack system using Docker Compose (FastAPI, Postgres, Redis, Celery, React UI) and implemented GitHub Actions CI/CD validating Ruff, MyPy, and Pytest.

**Tech Stack**: Python, FastAPI, React, TypeScript, Tailwind CSS, PostgreSQL, Redis, Celery, Docker, Pytest, scikit-learn, XGBoost, SHAP, Optuna.
